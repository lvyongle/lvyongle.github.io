# script：脚本记录

> 生产环境服务中执行命令，经常需要使用`history`来重现操作记录来进行复盘。
> 但是`history`命令只记录了当时的操作命令，没有记录当时的控制台的实时输出，出现异常进行复盘时有些力不从心。
> 因此使用`script`命令来记录操作日志势在必行！

## 安装
`Debian`系统下，`script`命令来自`bsdutils`安装包,可以使用`sudo apt install bsdutils`进行安装。

## 常用命令
- 录制脚本

```shell
# 开始录制命令
script
# 制定录制文件
script <fileName>
# 制定录制文件和时间轴文件
script --timing=<timing-fileName> <fileName>


# 结束录制
exit
```

- 回放脚本

```shell
# 没有指定时间文件
cat typescript
# 制定了时间文件
scriptreplay -t<timing-fileName> <fileName>
scriptreplay --timing=<timing-fileName> <fileName> -d <speed>
```
