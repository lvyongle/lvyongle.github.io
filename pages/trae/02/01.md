# 第1章 项目环境搭建

> 当前在`Deepin`系统中开发，以下是Linux环境安装准备内容。

## 1 开发环境准备
### `java`安装部署
- `java`版本：17.0.20
- 安装包下载：[https://www.oracle.com/cn/java/technologies/downloads/](https://www.oracle.com/cn/java/technologies/downloads/)
- 安装步骤：

```shell
tar -zxvf jdk-17.0.20_linux-x64_bin.tar.gz -C /opt/
echo "# Set JAVA_HOMR" >> ~/.bashrc
echo "export JAVA_HOME=/opt/jdk-17.0.20" >> ~/.bashrc
echo "export PATH=$JAVA_HOME/bin:$PATH" >> ~/.bashrc
source ~/.bashrc
```
### `maven`安装
- `maven`版本：3.9.16
- 安装包下载：[https://maven.apache.org/download.cgi](https://maven.apache.org/download.cgi)
- 安装步骤：

```shell
tar -zxvf apache-maven-3.9.16-src.tar.gz -C /opt/
echo "# Set MAVEN_HOME" >> ~/.bashrc
echo "export MAVEN_HOME=/opt/apache-maven-3.9.16" >> ~/.bashrc
echo "export PATH=$MAVEN_HOME/bin:$PATH" >> ~/.bashrc
source ~/.bashrc
```

## 3 数据库部署
### mysql8安装
- `mysql8`版本：8.1.0
- 安装方式：`docker-compose`
- 部署文件`docker-compse.yaml`
```yaml
version: '3.1'
services:
  mysql:          
    restart: always   
    image: mysql:8.1.0
    container_name: mysql8 
    ports:
      - 3308:3306  
    environment:
      MYSQL_ROOT_PASSWORD: 1234567   # 用户默认是root，指定MySQL的ROOT用户登录密码
      TZ: Asia/Shanghai        
    volumes:
     - ./data:/var/lib/mysql   # 映射容器里mysql的存储信息
     - ./config/my.cnf:/etc/mysql/my.cnf
```
- 配置文件：`config/my.cnf`
```text
[mysqld]
pid-file        = /var/run/mysqld/mysqld.pid
socket          = /var/run/mysqld/mysqld.sock
datadir         = /var/lib/mysql
secure-file-priv= NULL

lower_case_table_names  = 1

# Custom config should go here
!includedir /etc/mysql/conf.d/
```
- 启动服务：`docker-compose up -d`
- 访问服务：`root/1234567`
