# 第一章 课程总览
## 1. 什么是Markdown？
**简介**

---
• 定义：Markdown 是一种「纯文本→HTML」的轻量级标记语言。

• 特点：语法像打字聊天，10 秒成排版。

• 文件扩展名：.md 或 .markdown（GitHub、Gitee、Typora 通用）。

**Markdown 5 大刚需场景**

---
① 微信公众号 / 知乎一键排版

② GitHub README & 开源文档

③ Notion、Obsidian 等知识库导入

④ AI 提示词模板（ChatGPT、豆包、Kimi、文心一言等）

⑤ 电子书、博客静态网站（VitePress、Hexo）

**对比记忆表**

---
|工具	|学习成本	|输出格式	|适合人群|
|---|---|---|---|
|Word	|高	|.docx	|行政办公|
|Markdown	|极低	|HTML/PDF/ePub	|开发者/自媒体|
|LaTeX	|高	|PDF	|学术排版|

## 2. 为什么要学Markdown？

**痛点直击**

---
• 写 Word：调字号、刷格式，排版 30 min，写作 5 min

• 写 Markdown：打字同时完成排版，写作 5 min，排版 0 min

→ 省下的时间 = 多写 5 篇技术博客

**市场数据**

---

| 平台       | Markdown 内容占比 | 年增速 |
| ---------- | ----------------- | ------ |
| GitHub     | 93% README        | +12%   |
| 知乎专栏   | 67% 技术文章      | +35%   |
| 微信公众号 | 28% 技术号        | +58%   |

**结论**：不会 Markdown = 错过 1/3 流量红利



**一句话总结**

---

“写作 5 分钟，排版 0 分钟，SEO 全自动”——这就是当下创作者标配技能。



## 3. 5分钟完成你第一个Markdown文件

**准备工具（1 分钟）**

---

1. 在线编辑器：用电脑打开 [w3cschool 在线 Markdown](https://www.w3cschool.cn/tools/index?name=markdown)（免安装）
2. 本地推荐：Typora 1.8 绿色版（国内镜像下载）
3. 新建文件：右键 → 新建 → 命名 `hello.md`



**3 行代码速成模板（复制即用）**

---
```markdown
# 我的第一篇 Markdown
大家好，这是 **第一段** 文字。
- 快速
- 简洁
- 高效
```

把上面内容粘进 `hello.md`，立刻看到左侧源码、右侧预览。



**一键导出 & 分享（1 分钟）**

---

• **Typora**：Ctrl+Shift+E → 导出 PDF/HTML

• **在线编辑器**：点击「下载为md」→ 保存 Markdown 文件到本地

• **GitHub**：拖入仓库，自动渲染 README
