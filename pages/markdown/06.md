---

## 2. 项目2：5分钟把README.md做成SEO友好的静态网站

**1 分钟环境准备**

---
```shell
npm install -g vitepress
mkdir my-site && cd my-site
echo "# 我的文档" > index.md
npx vitepress init   # 一路回车
```

**2 分钟配置 SEO**

---

编辑 `.vitepress/config.ts`（或 `.js`）
```javascript
export default {
    title: 'Markdown 完全手册',
    description: '零基础到进阶的 Markdown 中文教程，持续更新',
    head: [
        ['meta', { name: 'keywords', content: 'Markdown,教程,VitePress,SEO' }],
        ['link', { rel: 'canonical', href: 'https://yourdomain.com' }]
    ]
}
```
**2 分钟部署 & 百度推送**

---

```shell
npm run docs:build        # 生成 dist
git add dist && git commit -m "deploy"
git subtree push --prefix dist origin gh-pages
# 百度推送
curl -H 'Content-Type:text/plain' \
--data-binary "https://yourdomain.com" \
"http://data.zz.baidu.com/urls?site=yourdomain&token=YOUR_TOKEN"
```

→ GitHub Actions 可自动完成最后两步（见 持续集成章节）。

## 3. 项目3：30分钟把微信公众号草稿变成排版精美的Markdown
**一键导出草稿 → Markdown**

---

- 登录 `微信公众平台`
- 草稿箱 → 选中文章 → 右上角「导出」→ 选「Markdown」
- 得到 `article.md` + `images/` 文件夹

**3 步适配 2025 微信限制**

---

|限制	|解决脚本（VS Code 正则）|
|---|---|
|封面图 2.35:1	|查找 `!\[.*\]\((.*)\)` → 替换 `<img src="$1" style="width:100%;aspect-ratio:2.35/1;object-fit:cover">`|
|代码块高亮	|全局替换 \``(\w+)\n → ```$1\n`（确保语言标识）|
|正文 3 万字	|状态栏查看字符数；超出拆分「上 / 下」两篇|


- 封面大图：900 × 383 px（2.35 : 1）
- 封面小图：500 × 500 px（1 : 1，用于转发卡片）
- 单张图片 ≤ 10 MB，长宽乘积 ≤ 600 万像素
- 正文 ≤ 3 万字，代码块需手动点一下才能触发高亮


**工具**

---

|工具	|网址	|作用	|步骤|
|---|---|---|---|
|md2wechat（在线）	|https://www.md2wechat.cn/	|微信专用渲染	|①左侧写/粘 Markdown → ②右侧复制 → ③粘贴到公众号后台|
|md-ityouknow	|http://md.ityouknow.com	|备用渲染站	|同上，支持代码行号|
|135 编辑器	|https://www.135editor.com	|封面图模板	|选「公众号封面 900×383」模板，直接改字换图|

**30 分钟实操 SOP**

---

① 10 min：在本地 VS Code 写完 article.md

② 5 min：把封面图裁成 900×383 & 500×500（用稿定/Canva/135 模板）

③ 10 min：打开 md2wechat → 粘入 → 选“微信代码主题” → 复制渲染结果

④ 5 min：粘贴到公众号后台 → 上传封面 → 预览 → 群发
