**一键批量脚本（Python 本地）**

---
```python
import openai, pathlib, sys
prompt = open('prompt.md').read()
text = pathlib.Path(sys.argv[1]).read_text()
res = openai.ChatCompletion.create(
model="gpt-3.5-turbo",
messages=[{"role":"user","content":prompt+"\n"+text}]
)
pathlib.Path('out.md').write_text(res.choices[0].message.content)
```

命令行：`python mdify.py raw.txt`
## 持续集成

**90 秒搭好流水线**

---
仓库根目录放 `.github/workflows/md2site.yml`
```yaml
name: 部署博客
on:
  push:
    branches: [ main ]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: peaceiris/actions-gh-pages@v3
        with:
          publish_dir: ./src       # Markdown 目录
          publish_branch: gh-pages # 自动发布分支
```

**百度自动推送（一键脚本）**
在 workflow 末尾追加：
```yaml
      - name: Push to Baidu
        run: |
          curl -H 'Content-Type:text/plain' \
          --data-binary @urls.txt \
          "http://data.zz.baidu.com/urls?site=https://你的域名&token=你的token"
```
`urls.txt` 由 `find ./src -name "*.md" | sed 's|.*/||;s|\.md$||'` 自动生成。

**本地一次性配置**

---

1. 域名已备案并在【百度搜索资源平台】添加站点 → 拿到 token
2. 在仓库 Secrets 新建 BAIDU_TOKEN
3. 提交 → Actions 跑完 → 1 分钟内百度收录
