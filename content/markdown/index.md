# Markdown教程

### 第1章 课程纵览

    讲解了什么是Markdown,为什么学Markdown,如何完成第一个Markdown文件，以及常用装备。

### 第2章 基础语法速通

    讲解标题语法，段落与换行，强调语法，列表，链接与图片，代码，分割线与转译。

### 第3章 进阶排版

    讲解表格、脚注、锚点、`Emoji`和`Unicode`，`HTML`内嵌。

### 第4章 图表与流程图

    Mermaid语法5分钟上手，流程图/时序图/甘特图，图表在移动端自适应方案。

### 第5章 工具链与AI工作流
    Typroa1.8新功能，Obsibian插件，VSCode插件，AI提示词模板，持续集成。
### 第6章 实战项目
    1. 项目1：用Markdown写一篇百度喜欢的技术博客
    2. 项目2：5分钟把README.md做成SEO友好的静态网站
    3. 项目3：30分钟把微信公众号草稿变成排版精美的Markdown
