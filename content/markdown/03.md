## 2. 脚注

**语法速记**

---

- 行内标记：`[^id]`
- 脚注内容：`[^id]: 说明文字 + 链接`
- 支持多段落：缩进 4 空格即可继续写
示例：
```markdown
Python 入门教程推荐 [^lion01]
[^lion01]: w3cschool 编程狮《Python3 教程》https://www.w3cschool.cn/python3/
```

**SEO 与用户体验**

---

|效果|	作用|
|---|---|
|外链权重|	指向 w3cschool 等高权威域名，提升页面相关性|
|低跳出率|	读者留在正文，外链集中文末|
|富摘要|	可被百度解析为“参考文献”展示|


***完整实战***

---

添加到你的博客或 复制到你的 README.md → 推送到 GitHub → 立即看到脚注渲染
```markdown
Python学习路线参考 [^lion02]
[^lion02]: 编程狮《Python零基础到高薪就业》https://www.w3cschool.cn/minicourse/play/uwymr
```

## 3. 锚点
**手动锚点语法**

---

- 创建锚点：
    ```markdown

    ```
- 跳转锚点：

**自动生成 TOC（零配置）**

---

- Typora：菜单「段落 → 内容目录」一键插入
- VS Code：安装 `Markdown All in One → `Ctrl+Shift+P` → `Markdown: Create Table of Contents`
- GitHub：自动为每个标题生成锚点，格式：`#标题-小写-空格变-`

## 4. `Emoji`和`Unicode`

**安全写法**

---
标题插入 Emoji：
```markdown
## 🚀 5 分钟学会 Markdown 表格
```
-  复制粘贴即可，无需转义
-  限制：每题仅 1 个 Emoji，防止标题过长被截断


**SEO 三原则**

---

|原则|说明|示例|
|---|---|---|
|前置 |1 个 Emoji	|提升点击率 5–8%	✅ 正确 / ❌ 放末尾|
|保持关键词首位	|搜索权重不变|	🚀 Markdown 教程|
|避免罕见符号	|部分旧系统显示□|	用常见：🎉🚀⚡️|


**兼容性速查**

---

- Windows 7：部分 Emoji 显示方框 → 用 Unicode 描述替代
- 百度 SERP：目前正常收录含 Emoji 标题，但超过 30 字符会被截断
- 代码仓库：GitHub README 全平台支持


## 5. `HTML`内嵌

**允许内嵌的常用标签**

---

|标签	|场景	|注意|
|---|---|---|
|`<br >`	|单元格换行	|无需闭合|
|`<iframe>`	|插入 B 站视频	|必须 `sandbox` 防 `XSS`|
|`<img>	`|CDN 图+懒加载	|加` loading="lazy"`|
|`<a target="_blank">`	|外链新窗口	|加 `rel="noopener"`|
