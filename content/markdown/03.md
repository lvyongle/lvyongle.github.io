## 2. 脚注

**语法速记**

---

- 行内标记：`[^id]`
- 脚注内容：`[^id]: 说明文字 + 链接`
- 支持多段落：缩进 4 空格即可继续写
示例：
```markdown
Python 入门教程推荐 [^lion01]
[^lion01]: w3cschool 编程狮《Python3 教程》https://www.w3cschool.cn/python3/
```

**SEO 与用户体验**

---

|效果|	作用|
|---|---|
|外链权重|	指向 w3cschool 等高权威域名，提升页面相关性|
|低跳出率|	读者留在正文，外链集中文末|
|富摘要|	可被百度解析为“参考文献”展示|


***完整实战***

---

添加到你的博客或 复制到你的 README.md → 推送到 GitHub → 立即看到脚注渲染
```markdown
Python学习路线参考 [^lion02]
[^lion02]: 编程狮《Python零基础到高薪就业》https://www.w3cschool.cn/minicourse/play/uwymr
```
